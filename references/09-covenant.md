# 判例 09：竞业限制——能不能锁住主播，以及会不会反噬

> **素材**：8 份法院公开发布的典型案例（上海一中院 2 份、上海二中院 2 份、北京三中院 1 份、
> 云南高院 1 份、广西高院 1 份、江西高院 1 份）；其中 1 份为同一案件在两个榜单重复收录，去重后 7 案。
>
> **脱敏说明**：这些是法院主动发布用于普法的典型案例，当事人已由发布机关化名处理。
> 本文件仍统一写作「主播某」「某公司」，不写案号。**但保留法院层级与地域**——
> 因为违约金尺度的地域差异是本案组的核心信息，删掉会导致用户误判。
>
> **使用纪律**：只写已核验的裁判逻辑，不复制原文，不补写未披露的金额或结论。

---

## 一句话结论

**主播可以是竞业限制的适格主体（看是否接触商业秘密，不看职级）；但把竞业限制条款写进
「合作协议」，同时又在为「不是劳动关系」辩护，是最自相矛盾的打法——那一条就是这个案子里
认定劳动关系的证据之一。**

---

## 09-1 主播是不是竞业限制适格主体：三个案子，一个标准

主播方的抗辩在三个案子里几乎一模一样——「**网络主播不属于高管或高级技术人员，
并非竞业限制义务适格主体**」。三次都没被采纳。

### 三个案子的认定路径

| 案件 | 主播的实际情况 | 法院认定其为适格主体的理由 |
|---|---|---|
| **某中院（上海）· 美妆直播间主播** | 在直播间工作，可获取销售数据、客户偏好、大促活动安排 | 上述信息**经公司采取保密措施 + 能为公司带来竞争优势 → 构成商业秘密** → 属负有保密义务的劳动者 |
| **某中院（上海）· 二手奢侈品带货主播** | 在职期间积累大量粉丝，离职后用与原账号相似的新号做同类带货 | 有大量粉丝的主播，**流量价值可直接或间接变现为巨大经济价值，属互联网公司核心价值员工**；系公司形象门面与人力资本；知悉直播运营数据 → 属「其他负有保密义务的人员」 |
| **某中院（北京）· 行政岗兼吃播节目运营与出镜** | 劳动合同岗位写的是「行政」，在职负责运营吃播节目并作为主播出镜 | 直播节目的**新颖性是核心竞争力**，关系到公司收益；其负责运营并出镜 + 双方签有合法有效的保密竞业协议 → 属「其他负有保密义务的人员」 |

### 这份标准怎么用

《劳动合同法》第 24 条把人员范围限定为三类：高级管理人员、高级技术人员、**其他负有保密义务的人员**。
主播是靠**第三类**进来的——所以争议焦点从来不是「主播是不是高管」，而是「**主播接不接触商业秘密**」。

**法院实际审查的四件事**：
1. 主播**实际接触**什么信息（不是合同里写了"接触商业秘密"就算，看岗位实际）
2. 这些信息**是否经公司采取保密措施**（有没有保密制度、权限分级、保密协议）
3. 这些信息**能否带来竞争优势**（销售数据、客户偏好、大促排期、选品逻辑、投流模型都算）
4. 或者，主播**本身的流量价值**是不是公司核心资产（粉丝量、影响力、是否公司培养出来的）

> **对甲方的直接含义**：想让竞业限制站得住，不能只在合同里写一句"乙方接触商业秘密"，
> 要有**保密措施的证据**——权限管理、数据分级、保密培训记录、离职交接清单。
> 三个案子里公司能赢，都因为拿得出"信息 + 措施 + 优势"这条链。

## 09-2 违约金能判多少：上海砍到与补偿等额，北京判了 100 万

这是本组材料里最值得注意的**地域分歧**，两份判决对同一问题的处理路径完全不同。

| | 上海某中院（美妆主播案） | 北京某中院（行政岗兼吃播案） |
|---|---|---|
| 约定违约金 | 竞业补偿总额的 **2 倍**（73,260） | **100 万元** |
| 约定补偿 | 按月支付，6 个月共 36,630 | 离职前月收入的 **30%** |
| 判决 | **调减为与补偿等额 36,630** | **全额 100 万** |
| 核心理由 | 该约定「未充分考虑违约情节、收入水平」，按公平原则调整；既保障公司商业秘密权益，又避免过度加重主播责任 | 主播「**未就违约金数额过分高于其违约行为造成的损失提交充分有效的证据**」，应承担**举证不能**的不利后果；且「违约金是否过高**不宜简单将补偿金数额与违约金数额相比较**，应综合考虑用人单位因此产生的损失程度」 |

### 这个分歧怎么理解

**不是"上海低、北京高"，而是两条不同的审查路径：**

- **上海路径**：以补偿金额为参照系衡量违约金是否相当。补偿 3.6 万，违约金 7.3 万 → 认为偏重，砍到等额。
- **北京路径**：明确**拒绝**以补偿金额作参照系，改用"公司实际损失"衡量，并且把**举证责任压在劳动者身上**。

北京路径与两个成文规则完全吻合：
- 法释〔2023〕13 号**第 64 条**：违约方主张违约金过分高于损失、请求减少的，**应当承担举证责任**
- 法释〔2023〕13 号**第 65 条**：以损失为基础衡量，兼顾合同主体、交易类型、履行情况、过错程度、履约背景

### 对甲方的实操结论

1. **违约金写高，不必然被砍**——北京案里 100 万全额支持，关键在于对方举不出损失证据。
2. **但地域要预判**：在上海系法院，违约金与补偿严重失衡时倾向于拉平；在北京系法院，
   更愿意看实际损失 + 举证责任。
3. **无论哪个路径，甲方都要准备"损失"的证据**：流量流失数据、粉丝迁移记录、客户/品牌方流失、
   替代主播的招募与培养成本。史某案里法院就是因为"未充分考虑违约情节与收入水平"才调的。
4. **补偿要给足、要给到位**：三个案子里公司都按约支付了补偿，这是主张违约金的前提。
   补偿没付，竞业限制对本就不产生约束力（见 A-12 关联的劳动争议解释一第 38 条）。

## 09-3 约定不明 → 整条落空，91.6 万全部驳回

**这是本组最贵的一份教训。**

### 事实

公司与主播同日签《竞业禁止协议》（离职后 2 年内不得自营或为他人经营竞争业务），
数月后又签《保护协议》，把触发条件具体化为：**在劳动关系存续期间，如员工在主播达人号
粉丝超过 10 万，且任一单月销售额达到 200 万元**（两个条件均须满足），才应遵守竞业禁止约定。

主播在职期间使用**两个账号**：
- 账号 A：**公司注册**，多人共用，粉丝超 10 万
- 账号 B：**主播个人注册**，专用，**离职时粉丝不足 10 万**

公司主张：两账号粉丝数相加超过 10 万，触发竞业限制。诉请违约金 **916,352 元** + 继续履行。

### 法院为什么驳回

1. **后签的《保护协议》优先**——《保护协议》约定了承担竞业义务的前提条件，应以它为准。
2. **「主播达人号」指向不明，按"员工专用账号"理解**——因为：
   - 公司账号多人共用，主播离职后未再使用、仍由公司运营，**不具备员工个人专属属性**
   - 个人账号仅由其专用，**更符合"主播达人号"的通常理解**
3. **粉丝数不能简单相加**——两账号直播内容相似，**粉丝存在重合**，相加会导致统计失真，
   不符合协议约定的计量逻辑。
4. 结论：个人账号粉丝不足 10 万 → **未触发竞业限制条件 → 无需承担违约责任**。

### 一个附带细节，也值得记住

主播曾在沟通中**询问竞业补偿的计算方式**，公司据此主张双方形成新的合意。法院不采：
主播后续**立即退回了公司支付的补偿金**，表明其明确拒绝履行竞业义务，**双方未达成新的竞业限制合意**。

> **含义**：员工"问了一句"不等于"同意"；**退回补偿金是明确的拒绝表示**。
> 甲方不要拿"他问过怎么算"当承诺证据。

### 法官提示（原文要点）

竞业限制条款的约定应当明确具体。用人单位与网络主播签订竞业限制协议需明确核心内容，
**主播账号、直播账号的归属，粉丝统计范围**等应避免模糊表述，**粉丝数、销售额等建议可量化**，
避免因约定不明导致协议无法履行。

### 对甲方的起草动作

| 要写清的东西 | 错误写法 | 正确写法 |
|---|---|---|
| 触发条件的账号 | 「主播达人号」 | 「乙方本人实名注册并专属使用的抖音账号（ID：【　】），不含甲方注册的共用账号」 |
| 粉丝口径 | 「粉丝超过 10 万」 | 「以【平台】后台【　年　月　日】数据为准，仅统计该单一账号，**不合并计算其他账号**」 |
| 销售额口径 | 「单月销售额 200 万」 | 「指该账号店铺后台已结算成交金额（扣除退款、取消订单），以平台账单为准」 |
| 多账号情形 | 不写 | 「乙方使用多个账号的，各账号分别独立计算，不累计」 |
| 条件未触发时 | 不写 | 「触发条件未满足的，本章竞业限制条款不生效，甲方已支付的补偿按不当得利返还」 |

**核心原则：凡是要拿来主张违约金的数字，都必须做到"打开后台就能核"。**
做不到可核，这一条就只是装饰。

## 09-4 🔴 反噬：竞业限制条款本身，是认定劳动关系的证据

这是整组材料里最反直觉、也最重要的一条。**三个不同省份的高院／中院，都把"合同里有竞业限制约定"
列为认定劳动关系的理由之一。**

| 案件 | 合同名称 | 法院据以认定劳动关系的要素（节选） |
|---|---|---|
| **某高院（云南）· 主播外出活动遇交通事故身亡，父母请求确认劳动关系** | 《网络主播销售服务合同》 | 合同「包含工作内容、工资待遇及发放、**竞业限制**等内容，**具备劳动合同的特征**」；公司对日常工作进行了**深度用工管理** → 确认劳动关系 |
| **某高院（江西）· 女主播追讨工资** | 《主播经纪合同》 | 公司**安排在规定时间和地点**直播、演艺、营销；每月按业绩发**保底工资和业绩提成**；主播**须遵守公司组织管理、休息休假、竞业限制等规章制度**；双方存在**较强的人身依附性** → 认定劳动关系，驳回公司"不存在劳动关系"的请求 |
| **某高院（广西）· 主播被移出工作群** | 《主播合作协议书》 | 约定每天/每月工作时间、**迟到旷工罚款**、休息休假及**休假申请审批手续**、工资构成与发放、**竞业限制** → 「虽名为合作协议，但劳动者需遵守工作规则、劳动纪律和奖惩办法，与合作关系的法律特征不相符」→ 认定劳动关系，另判**未签书面劳动合同二倍工资差额** + 解除补偿金 |

### 这意味着什么

**「竞业限制」是典型的劳动法概念。** 把它写进合作合同，等于在合同里主动标注
"我认为我们之间可能是劳动关系"。

三份判决的逻辑是一致的：
- 竞业限制 = 劳动关系项下的义务 → 出现这个词，说明双方关系带劳动法色彩
- 再叠加"迟到旷工罚款""休假申请审批""固定班次""保底工资" → 从属性成立 → 认定劳动关系

> 这与 `05-baseline-mcn-hr.md` D-01 的「一票否决清单」完全吻合，
> 而广西那份判决把清单里的词几乎逐字念了一遍——**这不是经验总结，是判决原文**。

### 后果比想象的重

被认定劳动关系后，甲方要面对的**不只是竞业限制失效**：

| 项目 | 依据 | 量级 |
|---|---|---|
| 未签书面劳动合同二倍工资差额 | 《劳动合同法》第 82 条 | 最多 11 个月工资（广西案实际判付） |
| 解除劳动合同经济补偿金 | 《劳动合同法》第 46、47 条 | 每满一年一个月工资（广西案实际判付） |
| 社保补缴 + 滞纳金 | 《社会保险法》 | 按工资基数全额补 |
| 工伤责任 | 《工伤保险条例》 | 云南案的背景正是外出活动途中事故身亡 |
| 竞业限制补偿（按月） | 《劳动合同法》第 23 条 | 离职前 12 个月平均工资 30% |

**云南那份最刺眼**：公司组织主播去省外参加活动，途中发生交通事故致主播身亡。
一旦认定劳动关系，这就是工亡，赔偿量级与"合作关系下的补偿"不在一个数量级。
**组织主播外出、参加线下活动、出差——这些安排本身就是用工管理的强证据。**

## 09-5 两条路，只能选一条

甲方想要"用竞业限制锁住主播"，同时想要"不是劳动关系、不上社保、不担工伤"。
**这两件事不能同时成立。** 从材料看，现实里只有两条路：

### 路径 A：认劳动关系，用足劳动法

| | 内容 |
|---|---|
| 做法 | 签劳动合同 + 单独签竞业限制协议，按月支付补偿，依法缴纳社保 |
| 竞业限制效力 | **最强**——09-1 三个案子都支持了公司主张 |
| 代价 | 社保、二倍工资风险、解除补偿、工伤、加班费 |
| 适格主体怎么写 | 岗位职责里明确接触"销售数据、客户偏好、大促排期、选品与投流逻辑"，并配套保密制度（权限分级、数据分级、保密培训留痕） |

### 路径 B：真合作，不用"竞业限制"这个词

| | 内容 |
|---|---|
| 做法 | 用**合作期内的独家排他** + **终止后的合理冷却期**，以商业对价换取，不引用《劳动合同法》 |
| 关键 | 不写"竞业限制""不竞争义务""保密义务"等劳动法术语，改写"独家合作""排他期""合作终止后的账号与商务交接期" |
| 对价 | 明确写成一笔商业对价（排在合作分成或单独支付），而不是"竞业补偿金" |
| 期限 | **短**——3～6 个月。期限越长，越像竞业限制，越容易被拉回劳动法框架审查 |
| 代价 | 约束力弱于劳动法竞业限制；对方若真是劳动关系，仍可能被重新定性 |
| 注意 | 不能同时保留劳动合同、社保、考勤、罚款、休假审批——否则路径 B 会被整体击穿 |

### 最糟的组合（务必警告用户）

> **一边在合作合同里写"竞业限制 + 违约金"，一边公司不缴社保、不签劳动合同、
> 还发着"保底工资"、用着"迟到罚款"和"休假审批"。**
>
> 这是 09-4 里三个案子的共同点，也是 MCN 行业最常见的写法。
> 结果是：**竞业限制没能有效锁住人，反而成了对方证明劳动关系的证据。两头输。**

## 09-6 三句实话（可直接放进审查结论）

1. **主播能不能被竞业限制约束，不取决于合同怎么写，取决于公司有没有"商业秘密 + 保密措施"的证据链。** 拿不出保密制度、权限管理、数据分级，条款写得再狠也站不住。
2. **违约金写多高都可能被判，关键看谁能举证损失。** 对方举不出，100 万也可能全额支持（北京案）；对方举得出、或补偿与违约金严重失衡，2 倍也会被拉到等额（上海案）。
3. **想锁人，先想清楚要不要认劳动关系。** 想在合作合同里既要竞业限制又要"非劳动关系"，是本组材料里输得最彻底的一种打法。
